# beee — Roblox Rare Username Bot

Telegram-бот на Python для поиска свободных ников в Roblox, генерации кандидатов через **Google Gemini**, оценки их редкости и автоматического подбора бесплатных HTTP/SOCKS5 прокси.

## Возможности

- **Проверка доступности ников:** проверяет ники через `auth.roblox.com/v1/usernames/validate` в многопоточном режиме с поддержкой пула прокси и авто-пополнения[cite: 9].
- **Генерация через Gemini:** подбирает редкие словарные английские слова по заданной теме и запускает проверку пачками[cite: 9].
- **Алгоритмы перебора и шаблонов:** полные переборы (`all4`, `all5`), красивые комбинации (`pretty`), чередования `CVCV/VCVC`, паттерны длиной 20 символов (`20L`), варианты слова (`variants`), поиск по маске (`scan` с `?` и `#`) и загрузка списков из `.txt`[cite: 9].
- **Оценка редкости (`/rate`):** выставляет баллы и грейд (`S`, `A`, `B`, `C`, `D`) с учётом длины, словаря/произносимости, визуальных паттернов и штрафов за похожие символы[cite: 9].
- **Сохранение прогресса и деплой:** сохраняет состояние, найденные ники и настройки в Redis (`REDIS_URL`) или в локальные файлы (`state.json`, `found.txt`, `checked.txt`, `proxies.txt`), а также поднимает HTTP-сервер на `PORT`[cite: 9].

## Быстрый старт

1. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```[cite: 10]
2. Задай переменные окружения и запусти бота:
   ```bash
   export TG_BOT_TOKEN="ваш_токен_от_botfather"
   export TG_CHAT_ID="ваш_telegram_id"
   export AI_API_KEY="ваш_gemini_api_key"
   python roblox_username_bot.py
   ```[cite: 9]

## Основные команды

| Команда | Что делает |
| :--- | :--- |
| `/menu`, `/start`, `/help` | Главное меню режимов и справка[cite: 9] |
| `/ai [число] [тема]` | Сгенерировать словарные слова через Gemini и проверить их на доступность[cite: 9] |
| `/rate <ник1> <ник2>` | Оценить редкость и грейд ников (`S`–`D`)[cite: 9] |
| `/name <ник...>` или текст без `/` | Быстрая проверка одного или нескольких ников[cite: 9] |
| `/all4`, `/all5`, `/pretty [3-6]` | Перебор комбинаций и красивых последовательностей[cite: 9] |
| `/variants <слово>`, `/scan <шаблон> [кол-во]` | Варианты слова и поиск по маске (`?` — буква, `#` — цифра)[cite: 9] |
| `/freeproxy`, `/reload` | Спарсить/проверить бесплатные прокси или перечитать `proxies.txt`[cite: 9] |
| `/status`, `/stop`, `/resume` | Статус текущей задачи, остановка и продолжение с сохранённой позиции[cite: 9] |
| `/found`, `/export`, `/delay`, `/notify`, `/id` | Найденные ники, выгрузка `found.txt`, пауза между запросами, порог уведомлений и свой ID[cite: 9] |

## Переменные окружения

- `TG_BOT_TOKEN` — токен Telegram-бота (также можно задать в константе `TOKEN` в коде)[cite: 9].
- `TG_CHAT_ID` — ID чата/администратора для доступа к командам (также можно задать в `ADMIN_ID`)[cite: 9].
- `AI_API_KEY` — API-ключ Google Gemini для команды `/ai`[cite: 9].
- `PROXIES` — список прокси через разделитель (если не задан, используется `proxies.txt` или авто-сбор бесплатных прокси)[cite: 9].
- `REDIS_URL` — строка подключения к Redis для хранения состояния между перезапусками[cite: 9].
- `CHECK_DELAY` — базовая задержка между проверками (по умолчанию `0.15`)[cite: 9].
- `PORT` — порт HTTP-сервера для платформ вроде Render[cite: 9].
- `RENDER` — если задано, бот учитывает эфемерность файловой системы при сохранении состояния[cite: 9].
